# Rhea Muncherji – Portfolio

Plain HTML/CSS/JS. No build step.

## Host on GitHub Pages
1. Create a new repository and upload everything in this folder (keep `index.html` at the top level).
2. Repo Settings > Pages > Source: "Deploy from a branch" > `main` / root > Save.
3. Your site will appear at https://YOUR-USERNAME.github.io/REPO-NAME/

## Netlify / Vercel / others
Drag and drop this folder into Netlify Drop, or import the repo into Vercel. No settings needed.
